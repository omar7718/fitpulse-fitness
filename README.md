Fitpulse Fitness - Modern Gym Website
A responsive, feature-rich fitness center website with modern design, multilingual support, and interactive functionality.

🌟 Features
Core Functionality
Responsive Design - Works perfectly on all devices

Multi-language Support - English and Arabic with RTL layout

Dark/Light Mode - Toggle between themes

Single Page Application - Smooth navigation without page reloads

Membership & Booking System
Plan Selection - Three membership tiers (Basic, Premium, Elite)

Class Registration - Interactive schedule with filtering

Class Management - Register/cancel classes with limits

Trainer Profiles - Detailed trainer information and booking

E-commerce Features
Supplement Store - Product catalog with shopping cart

Shopping Cart - Add/remove items and checkout

User Authentication - Login/signup with form validation

User Experience
Notifications - Toast notifications for user actions

Form Validation - Real-time validation with feedback

Loading States - Visual feedback during operations

Mobile Menu - Hamburger menu for mobile devices
🚀 Quick Start
Prerequisites
Modern web browser with JavaScript enabled

Local server for testing (due to CORS with local files)
🛠️ Technologies Used
HTML5 - Semantic markup

CSS3 - Modern styling with CSS variables and Flexbox/Grid

JavaScript (ES6+) - Interactive functionality

jQuery - DOM manipulation and event handling

Local Storage - User data persistence
